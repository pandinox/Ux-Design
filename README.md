# StockFlow — UX Showcase

To jest druga wersja projektu: prezentacyjna tablica UI/UX, wyglądająca podobnie do widoku projektu w narzędziu prototypowania.

## Co zawiera

- ekran startowy projektu,
- makiety wszystkich widoków aplikacji,
- opis głównych przepływów użytkownika,
- uzasadnienie decyzji UX,
- link do klikanego prototypu mobilnego w folderze `prototype`.

## Jak uruchomić

Otwórz `index.html` w przeglądarce albo wrzuć cały folder na GitHub Pages.

## Struktura

- `index.html` — strona showcase projektu UX/UI,
- `style.css` — style showcase,
- `prototype/` — działający prototyp mobilny.
