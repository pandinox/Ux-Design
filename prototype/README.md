# StockFlow — prototyp UI/UX

Klikany prototyp mobilnej aplikacji magazynowej przygotowany jako projekt zaliczeniowy.

## Temat
Aplikacja magazynowa dla małych firm i sklepów internetowych.

## Widoki
Projekt zawiera więcej niż wymagane minimum 5 widoków:

1. Logowanie
2. Dashboard
3. Lista produktów
4. Szczegóły produktu
5. Dodawanie/edycja produktu
6. Skaner kodów
7. Wynik skanowania
8. Przyjęcie towaru
9. Wydanie towaru
10. Raporty
11. Ustawienia

## Założenia UX
- Projekt Mobile First.
- Najważniejsze akcje są dostępne z dolnej nawigacji.
- Operacje magazynowe można wykonać w krótkiej ścieżce: skan → produkt → przyjęcie/wydanie.
- Duże przyciski ułatwiają obsługę jedną ręką.
- Komunikaty potwierdzają wykonanie akcji.
- Interfejs ogranicza liczbę elementów na ekranie, aby zmniejszyć ryzyko błędu podczas pracy w magazynie.
